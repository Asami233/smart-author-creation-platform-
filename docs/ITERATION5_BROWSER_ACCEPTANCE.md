## 验收步骤

1. **基础保存**：在长章末尾输入带浏览器名称的短句，等待自动保存版本更新；切短章并返回，刷新，确认新增内容完全保留。记录前后版本。打开查找、跳章、专注模式；正文 Escape 能退出专注。
2. **真实输入法**：启用系统中文输入法，在正文输入拼音但保留候选框；候选阶段按 Escape 应先取消候选，不能退出专注。正常提交后再按 Escape 才退出专注。在查找和跳章输入框重复：Enter 第一次确认组词，不能同时执行查找或跳章；提交后的下一次 Enter 执行操作。用实际输入法操作，不用逐字输入 API 或合成事件替代。
3. **实际缩放**：通过浏览器界面分别设置 80%、100%、125%、150%，每档检查目录、正文、工具栏、查找/跳章弹窗、保存状态和右栏。输入并保存短句，确认目标按钮可操作、正文可滚动、无关键控件遮挡。结束恢复 100%。
4. **选区粘贴**：在合成短章选中文本，粘贴纯文本与含粗体/链接的富文本，正文只接收纯文本。粘贴空内容、图片或只有 HTML 的内容时不得删除选区；一次撤销能恢复有效文本粘贴，刷新后仍正确。若浏览器自动从 HTML 生成纯文本，注明该条件，不能将其当作“没有纯文本”的证据。
5. **复制许可**：使用合成的 AI 预览文本或冲突草稿，先在允许状态复制并核对剪贴板；再用浏览器提供的设置/提示测试拒绝场景，记录实际写入结果。站点“剪贴板”设置不一定等于所有写入均被拒绝，不能强行把浏览器允许的用户点击复制判为失败。可另用下述 HTTP 权限策略测试真正的 API 拒绝：应不显示成功、剪贴板保持原值，并出现可手动复制的提示。缺少 API、系统拒绝和等待期间分别注明；测试替身不能作为真实权限证据。

### 权限策略拒绝入口

正常隔离服务运行在 5179 时，另开终端：

```powershell
node scripts/clipboard-policy-proxy.mjs
```

测试入口 `http://127.0.0.1:5181/` 只代理本机 5179，给响应添加 `Permissions-Policy: clipboard-read=(), clipboard-write=()`，不替换 Clipboard API。用独立 Edge/Chrome 验收，不改变正常页面的策略。脚本拒绝外站 Origin、Host 和跨站请求；结束关闭该临时代理。

Firefox/Safari 的 Clipboard 权限模型不同，不支持 `clipboard-write` 的 Permissions API 权限项；应记录各浏览器实际行为和策略支持，不能要求不存在的设置。[MDN Clipboard API](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)

本轮内置浏览器在该策略下仍能写入会话剪贴板，没有产生拒绝结果，不能据此记为权限拒绝通过。项目所有者确认独立 Edge 的 5181 页面结果与预期一致：复制失败提示、剪贴板未被改变、正文保留。5179 初次未触发冲突；独立 Edge 允许复制复验未收到结果，内置 Chromium 正常复制已通过。独立浏览器版本与操作结果来自项目所有者人工报告，尚未收到截图，不宣称为 Codex 自动操作证据。
