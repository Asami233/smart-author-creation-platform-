## 三、视觉风格与字体统一规范（依据 `docs/UI_STYLE_GUIDE.md`）

### 1. 字体族（Font Stack）
- **绝不引入外部 CDN 字体**，全面采用操作系统原生字体栈：
  - **文学标题与正文**：`font-serif`（`ui-serif, "Songti SC", "Noto Serif SC", SimSun, "Source Han Serif SC", serif`），呈现东方宣纸墨香质感；
  - **交互控件、标签、说明**：`font-sans`（系统级无衬线字族，包含 PingFang SC、Microsoft YaHei 等）；
  - **版本号、字数、Token 指标**：`font-mono`（等宽字体清晰对齐）。

### 2. 字号与控件尺寸收口
- **正文编辑器**：字号统一为 `18px`，行高 `1.9`，段落间距 `0.75em`，段首两汉字缩进 `2em`；
- **操作按钮与表单控件**：
  - 核心主按钮、输入框、下拉框：字号 `14px / 15px`（`text-sm`），高度标准统一为 **40px (`h-10`)**；
  - 次级辅助按钮、行内操作：高度 **32px (`h-8`)**；
  - **全面取缔 10px～12px 的过小可点击交互控件**，保证移动端/触控板/桌面鼠标点击舒适度。
- **状态栏**：固定高度 36px，字号 13px，字数统计与保存状态一目了然；
- **AI 助手预览区**：字号统一为 `15px`，无衬线易读样式。

### 3. 色彩体系与圆角规范
- **桌面背景**：`#F4F2ED`（暖米灰 Desk）；
- **纸张与卡片底色**：`#FFFEFB`（宣纸暖白 Paper）；
- **主文字**：`#202923`，次级文字：`#56615B`，弱化提示：`#85918A`；
- **边框分隔线**：`#DEDFD9`；
- **品牌松针墨绿**：`#176B5B`（Hover：`#12584A`）；
- **圆角收口**：常规按钮与输入框 `rounded-lg` (8px) / `rounded-xl` (10px)；弹窗与大卡片 `rounded-2xl` (16px)。

### 4. 辅助检查面板折叠（Inspector Collapse）
- 在编辑区顶部工具栏右上角新增【折叠/展开右侧面板】按钮（图标：`PanelRightClose` / `PanelRightOpen`）；
- 折叠时右侧栏设置 `.is-collapsed`（`display: none !important`），为正文编辑区释放 320px 宽度，显著改善 1366×768 及紧凑屏幕下的沉浸写作体验。

### 5. 分卷删除与【未分卷】分组展示
- **未分卷分组**：章节列表中若存在 `volumeId` 为空或关联已不存在的分卷，自动归入【未分卷】分组展示；
- **分卷安全删除**：
  - 在分卷标题右侧提供删除按钮；
  - 点击弹出明确二次确认提示：*“确定要删除分卷《xxx》吗？系统将执行安全移除：本卷中的所有章节将完整保留，并转入【未分卷】列表；卷级大纲将自动保留为作品级大纲；分卷记录本身将被移除（不会随卷删除任何正文内容）”*；
  - 触发 `DELETE /api/volumes/:volumeId`，前端将原属于该卷的章节 `volumeId` 设为 `null`，平滑落入未分卷分组；
  - 若当前选中的章节正好位于被删除的卷内，当前编辑章节保持选中与正文内容不受任何影响。

## 四、对后端（Codex / GPT）的后续需求与建议

为配合下一阶段规划（G0/G1 达标与迭代 3），前端提出以下接口与契约需求：

1. **分卷整书排序接口（规划中）**：
   - 现阶段前端已支持大纲排序 (`/api/works/:id/knowledge/outlines/reorder`) 与章节重排 (`/api/works/:id/chapters/reorder`)；
   - 建议在迭代 3 新增 `POST /api/works/:id/volumes/reorder`，参数 `{ volumeIds: string[] }`，支持作者拖拽或上下移动分卷顺序。
2. **AI SSE 流式输出接口（规划中）**：
   - 目前 AI 生成通过 `POST /api/ai/generate` 进行整体等待返回；
   - 建议提供基于 Server-Sent Events (SSE) 的流式接口（如 `POST /api/ai/stream`），支持打字机逐步渲染与前端主动 `AbortController` 中断。
3. **真实多端每日净增字数统计（规划中）**：
   - 当前今日字数为客户端本地正向产出统计（已修复为北京时间自然日且初值为 0）；
   - 建议后端后续在 `GET /api/works/:id/stats` 中补充跨设备多终端聚合的 `todayNetWords` 与 `recentTrends`，前端即可无缝替换本地 localStorage 统计。
