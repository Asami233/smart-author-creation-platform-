## 1. 产品与页面交付

- AI 建议改为 `fetch` + SSE 流式预览，模型片段逐段显示在预览区。
- 生成中显示“停止生成”；停止后标记“未完成”，已到达的片段可以复制，但“采纳并写入”保持禁用。
- 只有收到正式 `done` 事件后才允许采纳。生成内容仍不自动覆盖正文。
- 切换作品或章节会取消旧请求并隔离旧结果，迟到片段不会进入新作品。
- 采纳时把模型输出作为纯文本构造段落，不把模型文本当 HTML 注入富文本编辑器。
- 提示词上限与正式契约对齐为 2,000 字符。

## 2. 接口与正式契约

新增 `POST /api/ai/generate/stream`，请求体与既有 `/api/ai/generate` 兼容，旧接口不变。正式事件类型为 `contracts/types.ts` 的 `AiStreamEvent`：

- `start`：请求 ID、动作、模型。
- `delta`：新增纯文本片段。
- `done`：可空 token 用量与本次显式上下文计数。
- `error`：稳定的安全错误码和用户可读信息。

握手前错误仍用普通 JSON 非 200 响应；握手后错误用 SSE `error` 事件。客户端取消以 `AbortSignal` 为契约，无独立取消接口，也不依赖 SSE 自动重连。详细语义已写入 `docs/API_CONTRACTS.md`。

## 3. 服务端、安全与隐私

- 模型 API Key 只在服务端解密并写入供应商请求头，不进入事件、浏览器状态或错误信息。
- 仅转发请求中用户明确提供的上下文；服务端不会自行读取整部作品。
- 沿用同源校验、会话/本地单作者身份、每日请求上限和公共 HTTPS 供应商地址限制。
- 上游 401/403、429、普通错误、无流式正文、非法 JSON、异常断流、空输出和超长输出均映射为稳定安全错误。
- 供应商原始错误正文不透传。
- 总流式时限 120 秒；单帧上限 100 万字符；总输出上限 20 万字符。
- 客户端停止或断开时中止上游读取。只有收到完整 `[DONE]` 并成功完成本地记录后才发送 `done`。

- HTTP 200，`Content-Type: text/event-stream; charset=utf-8`。
- 顺序为 `start → delta × 4 → done`，拼接结果为“流式验证成功”。
- `done` 返回 `inputTokens: 88`、`outputTokens: 4`。

- 空请求返回 400；跨源写请求返回 403。

- 完整流式结果显示“AI 建议片段（预览）”，内容为“浏览器流式验收成功”，“采纳并写入”可用。
- 长流式生成时显示“AI 建议片段（生成中）”与“停止生成”，此时“采纳并写入”禁用。
- 点击停止后立即显示“已停止生成；未完成的片段不会写入正文”，标题变为“未完成”，停止按钮消失，“采纳并写入”继续禁用。
