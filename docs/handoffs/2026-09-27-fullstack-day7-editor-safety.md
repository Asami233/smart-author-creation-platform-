## 目标与产品边界

长篇写作首先不能因断网后的重复提交造成重复版本、重复统计或覆盖较新的稿件。本批将现有 HTML 富文本正文明确标记为格式版本 1，为未来换用 TipTap 留出迁移边界；当前仍使用原生 `contentEditable`，不声称完成 TipTap 替换。

## 已交付

- `PATCH /api/chapters/:chapterId` 接受可选 UUID `saveId`。客户端同一待保存草稿的重试复用 ID；服务端只在该保存仍为最新、字段与预期修订完全匹配时确认重放，不再次写入。ID 复用但内容变化返回 409；被后续保存覆盖后不跳过修订冲突。内部写入标识与客户端幂等 ID 分开，版本快照和每日正向字数只随实际成功写入发生。
- 章节响应、章节列表和作品快照包含 `contentFormatVersion: 1`。迁移 `drizzle/0005_brave_otto_octavius.sql` 给旧章节默认补 1，新增章节显式写 1；版本恢复清除旧的客户端保存 ID。备份导出保留格式版本，旧版备份缺字段按 1 解析，未知版本拒绝导入。
- 工作台草稿每次新输入生成新保存 ID，未知网络结果重试原稿时复用 ID；浏览器富文本粘贴只取剪贴板纯文本，插入为文本节点，不接收粘贴来源的标签和事件属性。段落换行通过 `pre-wrap` 保留。
- 更新 [API 契约](../API_CONTRACTS.md) 的请求示例、重放条件和格式兼容语义。
