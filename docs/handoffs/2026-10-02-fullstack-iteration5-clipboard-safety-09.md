# 迭代 5 第十批：剪贴板选区保护与复制反馈

日期：2026-10-02。负责人：Codex。

## 变更

### 前端

- 新增 `lib/client/editor-clipboard.ts`，接收粘贴事件里的纯文本；缺失或空文本返回无操作，保留空格、换行和字面 HTML 字符。
- `app/page.tsx` 粘贴处理遇到无文本时直接消费事件，不分发空字符串替换事务。此前 `insertText("")` 会删除当前选区；没有纯文本的剪贴板不能导致正文删除，也不能回退解析 HTML。
- AI 建议与冲突草稿复制共用等待写入结果的处理。开始复制时清除旧的成功提示，浏览器确认写入后才显示“已复制”；权限拒绝或 Clipboard API 缺失时提示手动复制，不产生未处理的 Promise 拒绝。
- 新增四项回归测试，覆盖缺失/空/HTML-only/文件数据、空白与字面文本、等待写入、拒绝和 API 缺失。

### 接口、契约、迁移与兼容性

- 本批无 API、契约或数据库迁移变更；不新增权限请求，不扩大浏览器权限。
- 正文格式仍为 HTML v1，粘贴仍只接收纯文本。无纯文本粘贴成为无操作，正常粘贴和撤销语义保持兼容。
- 无共享配置或依赖变更；保留已有未提交工作。

## 真实页面验收

环境：Codex 内置 Chromium，当前生产构建，`http://127.0.0.1:5179/`，复用合成数据隔离库 `.wrangler/iteration5-endurance-20261001`。本批启动的服务在验收后关闭。

1. 进入“持续写作切章检查”，原文 15 字、v1。编辑器 Ctrl/Cmd+A、Ctrl/Cmd+C 后读浏览器会话剪贴板，确认选中了完整合成正文。
2. 仅写入 `text/html` 后 Ctrl/Cmd+V：全文、HTML 和版本均未改变。
3. 写入空纯文本后粘贴：全文与 HTML 未改变；再次复制确认完整选区仍保留。
4. 提供不同的 `text/plain` 与含粗体/链接的 HTML：正文等于指定纯文本，字面 `<b>` 保持为文本，无新增粗体或链接节点。
5. 一次撤销恢复原文，刷新后仍为原文；最终短章 v3、wordCount 15。
6. 返回长章，确认全选复制得到 109,419 个非空白字符，再粘贴仅 HTML：完整 HTML 不变，仍为 v575。
7. 正式章节接口复核：长章 v575 / 109419、短章 v3 / 15，均与预期 HTML 完全一致。读取的浏览器 error 日志为空。
