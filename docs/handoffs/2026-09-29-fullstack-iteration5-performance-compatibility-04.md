## 1. 已完成的修改

### 长章文本分析

- `lib/client/chapter-text.ts` 增加每个工作台独立的单条分析缓存，同时返回纯文本与 Unicode 码点字数。只保留最近一次 HTML，不按章节或历史草稿无限累积缓存，不做跨账号全局缓存。
- 计数不再通过 `Array.from` 创建十万元素的临时数组；保留中文、补充平面字符、实体与列表项目符号的原有计数口径。
- `app/page.tsx` 的输入计数、当前章字数、目录/全书统计、AI 上下文复用分析结果。仍同步更新本地正文与保存队列，沿用 650 ms 防抖、saveId、expectedRevision 和冲突保护；没有为了性能延迟登记草稿。
- 尚未优化每次输入的 `editor.getHTML()` 序列化、整页 React 渲染和本地存储写入；本批不宣称完整按键链路达到某个延迟目标。

### RSC 预取与点击导航

实际问题不仅是控制台噪声：修复前，点击“登录 / 注册”也停留在原页。

本地证据：

1. `vinext@1.0.0-beta.5` 的 `dist/shims/link.js` 动态导入 `navigation.js`，再读取 `getPrefetchInterceptionContext` / `navigateClientSide` 等具名导出。
2. 旧生产包 `shield-check-6rruA1cr.js` 的预取异常在第 2 行 4294 列，调用缺失的 `getPrefetchInterceptionContext`；点击异常在同一行 11743 列。
3. 对应动态导入返回 `index-DpLC0DYO.js` 的模块对象，但该产物导出表只有重命名的短名称，并无上述属性。安装包源码含原名，生产产物与调用方期待不一致。

这定位到了**当前构建组合的动态导入模块导出不匹配**，没有证明具体是哪一个上游插件/打包器的单独缺陷，也没有标注某个新版本已修复。

处理方式：新增 `components/navigation/document-link.tsx`，用原生 `<a>` 承载现有五个文件里的跨页面链接：登录菜单、登录页返回、个人页返回、访客认领页返回/进入、会话页返回。登录按钮用 `asChild`，避免链接嵌套按钮。

- 这是应用层兼容回退，**不是对框架预取内核的修复**。
- 代价是这些链接执行整页导航、不预取；正常浏览器打开新标签等链接语义保留，原有 `beforeunload` 监听不被客户端路由绕开。
- 未屏蔽控制台错误，未修改 `node_modules`、锁文件或构建配置，未批量升级依赖。既有 `router.push` 调用未改，本轮不声称所有已登录路由流程都复验完毕。
- 未来恢复 `next/link` 前，必须同时验证生产构建的预取与实际点击，不可仅将 `prefetch` 设为 false 就宣告修好。

### 桌面布局与准确文案

- `app/globals.css`：分卷标题与操作区分行，避免窄目录把标题挤没；AI 身份区改两列并将配置按钮放到下一行，避免标题/加密标记被挤成竖排。
- 上下文标题和 Token 预算可换行，不改变勾选内容或 AI 请求范围。
- 登录品牌说明移除“毫秒级”“误关也不丢稿”“百万字不卡顿”等未经验证承诺，明确失败草稿仅在当前窗口；访客入口改称本机访客工作台，个人页文案改为本地优先。

## 3. 真实页面与隔离数据验收

使用生产构建、本地 `http://127.0.0.1:5178` 与 `.wrangler/day7-acceptance-20260927`。日常 `.wrangler/state` 未触碰。合成章 `4f6a757e-ea89-4492-a4e8-55ae5fb2f224`，标题“十万字千段性能验收”。

1. 经 API 新建 100,000 字 / 1,000 段测试章，浏览器切入后 DOM 检查段落与字数完整。
2. 末尾按字符输入“连续输入验收。”20 次，共 140 字。自动化操作两次达到工具约 5 秒截止，分别已输入 66、累计 131 字；先读实际正文，再补未输入部分，最终准确 140 字，未盲目重输。这个现象不是已经测得的浏览器延迟指标。
3. 实际接口读取到 100,140 字、修订 4；搜索“起”得到 1,000 处；全部替换为“始”后无旧匹配，点击一次撤销恢复 1,000 处，段落数不变。
4. 自动保存到修订 5。重新打开最终构建后，DOM 仍为 1,000 段 / 100,140 字，末尾与 20 次完整短句相等；查找短句恰好匹配 20 处。
5. 最终构建真实检查 1024×768、1280×720、1440×900。1024 和 1440 的文档宽度等于视口；1280 的专注模式也无全页横向溢出。窄桌面 AI 标题与卷名不再被挤坏；工具栏能换行。1280 验证进入/退出专注。
6. 新标签页控制台无 error/warn；登录链接进入登录页、返回工作台成功。个人页、认领页、会话页的返回链接也实际点击成功。只验收导航，不提交登录、认领、注销或会话修改操作。
