# 界面与字体规范 v1

日期：2026-09-23
状态：供 Gemini 下一轮实现的设计基线；本文件不代表页面样式已经修改。

## 1. 视觉目标

保留现有墨绿、暖白纸张与轻微书卷感，营造长时间写作时安静、清楚的桌面工具。装饰优先放在品牌或空状态，正文与工具操作使用稳定的排版。

主次顺序：正文 → 保存状态和当前章节 → 目录与资料 → AI 工具 → 写作激励。AI 和达标动效不能抢走编辑焦点，庆祝默认采用可关闭的轻提示。

本轮覆盖写作工作台、作品选择/创建、四类设定、版本/关联/导出/回收站、AI 配置、登录注册、个人中心、统计页面。沿用现有路由与组件，不为视觉统一创建一批空页面。

## 2. 字体家族

| 用途 | 规划字体栈 | 使用原则 |
| --- | --- | --- |
| 界面、导航、按钮、表单、说明 | Microsoft YaHei, PingFang SC, system-ui, sans-serif | 全站默认，优先本机字体，中文操作文字不用装饰宋体 |
| 小说正文、章节标题、少量品牌标题 | Noto Serif SC, Songti SC, SimSun, serif | 保留书卷感；本机没有首选字体时正常回退，不假设已安装 |
| API 示例、必要技术标识 | Consolas, SFMono-Regular, monospace | 不用于普通中文表单和长说明 |

复用/统一现有 --font-sans、--font-serif；在全局样式中集中声明，不逐组件定义字体。不要为了本轮美化安装字体依赖或引入外部字体 CDN。若未来打包字体，单独确认授权、体积和加载影响。

正文默认采用上述衬线字体；无衬线正文与阅读字号偏好可在 G4 增加。界面字体统一和作者阅读偏好是不同配置，不能把整个工作台随正文字号一起放大。

## 3. 字号、行高和字重

以下数值均为 CSS 像素，根字号基线为 16px。实现时优先换算成 rem 并映射到语义令牌，尊重浏览器缩放；不要把根字号设为 62.5%。

| 语义令牌建议 | 场景 | 字号 / 行高 | 字重 |
| --- | --- | --- | --- |
| text-caption | 日期、字数、非关键辅助信息 | 12 / 18 | 400 |
| text-secondary | 帮助文字、次要描述、保存状态 | 13 / 20 | 400～500 |
| text-ui | 导航、按钮、标签、目录项、表格 | 14 / 22 | 400；选中/标签 500 |
| text-body | 表单输入、卡片描述、AI 指令和预览 | 15 / 24 | 400 |
| text-section | 面板与分组标题 | 16 / 24 | 600 |
| text-dialog-title | 弹窗标题 | 20 / 28 | 600 |
| text-page-title | 作品总览、设定页、个人中心标题 | 24 / 32 | 600 |
| text-chapter-title | 正文章节标题 | 28 / 40 | 600 |
| text-editor | 小说正文 | 18 / 34 | 400 |

- 12px 仅用于低频辅助文字；按钮、表单、错误和正文不用 10～12px。
- 正文默认 18px、行高约 1.9；后续阅读偏好可提供 16/18/20/22px。正文默认不额外增加字符间距。
- 正文普通段落首行缩进 2em，段间距约 0.75em；标题、列表、引用不套普通段落缩进。
- AI 预览默认 15px / 24px，无衬线；长篇预览可使用统一的阅读容器，不缩到 13px 宋体塞进窄卡片。
- 数字统计使用等宽数字特性，不因数字变化造成按钮和卡片跳动。
- 同级组件不随页面随意改变标题大小；只保留 400、500、600 三档常用字重，700 留给极少量强调。

## 4. 色彩与状态

| 语义 | 起始值 | 用途 |
| --- | --- | --- |
| 页面背景 | #F4F2ED | 工作台背景 |
| 表面 | #FFFFFF | 卡片、弹窗、表单 |
| 阅读纸张 | #FFFEFB | 正文纸面 |
| 主文字 | #202923 | 标题和正文 |
| 次要文字 | #56615B | 帮助、状态、说明 |
| 辅助文字 | #68716C | 时间等次要信息，仍需可读 |
| 主色 | #176B5B | 主要按钮、选中标识、焦点 |
| 选中底色 | #E5EEEA | 目录/标签选中背景 |
| 分隔线 | #DEDFD9 | 非交互分隔 |
| 危险 | #B42318 | 删除、失败 |
| 警告 | #8A5B16 | 待保存、冲突警示的起始色 |

这些是设计起始值，Gemini 必须检查实际文字/背景组合。项目内部验收目标：普通文字对比度至少 4.5:1，焦点及关键控件边界至少 3:1；本轮不宣称完成外部无障碍认证。浅色分隔线不能作为唯一的输入框/焦点标识。

成功、保存中、失败和冲突都用文字配合图标表达；不能只变颜色。保存至本机服务时使用“已保存”，未实现云端同步时不要展示“已同步到云端”。

## 5. 间距、形状与组件

- 间距统一采用 4、8、12、16、24、32、48px。表单项间距 16px，区块间距 24px。
- 常规控件高 40px，紧凑目录/工具栏控件可 32～36px；图标按钮至少 32×32px。错误提示不能挤到控件内部。
- 输入框/按钮圆角 8px，卡片 12px，弹窗 16px。圆角胶囊仅用于短状态或标签，不把所有操作都做成胶囊。
- 普通卡片以边框和留白区分；浮层使用轻阴影。避免多层描边、渐变、阴影同时叠加。
- 图标统一沿用现有图标库：通常 18px，紧凑工具 16px，导航 20px；统一描边。图标按钮必须有可访问名称，提示不只依靠悬停。
- 一个弹窗通常一个主按钮，其他为次要或危险操作。主按钮位置稳定；提交中阻止重复点击，失败保留输入。
- 标签不作为 placeholder 使用。字段错误紧邻字段；请求错误放在区域顶部，必要时提供重试。

## 6. 工作台与滚动

- 保留“窄导航 → 卷章目录 → 写作区 → AI/本章信息”的结构。导航建议约 64px、目录 240～280px、右面板 300～340px；正文区域弹性占据剩余空间。
- 纸面最大宽度约 820px，正文有效阅读宽度约 600～700px；宽屏不把每行拉满。
- 1366px 宽时优先收起非活动辅助面板或以可打开的抽屉呈现，不能靠缩小字号勉强保留全部列。被收起的功能有明显入口。
- 顶栏、工具栏、保存状态占固定区域；目录、正文、右面板各有自己的滚动容器。弹窗只有内容区域滚动，标题和操作区可见。
- 保留已修复的滚轮行为。检查 flex/grid 子节点的可收缩尺寸，避免滚轮落在内层时整页一起移动。
- 当前 paper-scroll 和 rich-editor 都有 50vh 留白。下一轮核对是否重复制造过长空白，保留一处合理写作余量，不能为取消空白破坏末行可达性。
- 不靠写死多个“视口高度减常量”来拼弹窗和面板；优先使用现有容器高度和弹性布局。
- 必测 1366×768、1440×900、1920×1080；另测 125% 与 150% 浏览器缩放。保持主要写作操作可达，允许面板折叠和工具栏重排。
- 移动端暂不作为完整编辑目标。窄屏保留清楚的桌面使用提示；桌面浏览器缩放后不应直接失去已打开稿件的操作入口。

## 7. 页面整理顺序

| 批次 | 页面/区域 | 具体目标 |
| --- | --- | --- |
| UI-1 | 全局字体、表单、按钮、弹窗 | 建立语义令牌，清理零散微小字号，统一标题和错误状态 |
| UI-2 | 主工作台、目录、AI 面板 | 正文更易读，保存状态清楚，滚动和右栏收放稳定 |
| UI-3 | 作品入口、设定、历史、导出、回收站 | 相同列表/详情结构，相同操作位置，真实空/加载/失败状态 |
| UI-4 | 登录注册、个人中心、统计 | 同一视觉语言；统一标签、数字、提示、表单密度 |

UI-1 完成后先自查一张工作台截图和一张复杂弹窗截图，再批量应用。不要一次把所有组件改成新的交互模型。

## 8. 文案、反馈与动效

- 用户文案用“参考内容”“连接失败”“保存冲突”等可理解的词，不在普通写作流程堆放后端技术术语。
- API 地址、模型名称、密钥是否已保存属于配置决策所需信息，应保留；不把密钥写入 URL、日志或浏览器存储。
- 空状态说明原因与下一步，失败状态不伪装成空列表；无真实数据时不放演示数字填充页面。
- 常规过渡 120～180ms；尊重减少动画偏好。取消持续漂浮、闪烁或会打断写作的大面积庆祝动画。
- 焦点可见；弹窗打开聚焦合理元素，关闭后回到触发位置，Esc 关闭不能绕过必要的未保存保护。

## 9. 完成标准

Gemini 交接应附：覆盖页面清单、实际字体与字号令牌、三种尺寸截图、缩放/键盘/滚轮检查、表单与弹窗状态、保存与切换回归结果、未通过项。

不增加新后端契约、不改变正文存储格式、不替换编辑器；这些属于后续阶段。视觉验收只对本次截图与行为负责，不能因为页面更美观就标记数据安全验收通过。
